# Баржа

Программа симулирует погрузку и выгрузку бочек на барже.
Каждый отсек работает как стек (LIFO) — последняя 
положенная бочка достаётся первой.

## Задача

Баржа проплывает через N доков. В каждом доке либо 
погружается бочка в отсек, либо выгружается крайняя бочка.
Программа выводит максимальное число бочек на барже 
или "Error" если была нарушена логика.

## Как собрать

g++ -std=c++17 -o barge main.cpp barge.cpp stack.cpp ui.cpp

## Как запустить

./barge

## Структура проекта

- stack.h / stack.cpp — стек на связном списке
- barge.h / barge.cpp — логика симуляции
- ui.h / ui.cpp — интерфейс и ввод/вывод
- main.cpp — точка входа
